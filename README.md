# Padaria e Confeitaria Boas Novas

Site da padaria Boas Novas (R. Tomé de Souza, 92, Benfica, Juiz de Fora/MG).

- `index.html`: a página inteira (HTML, CSS e JS num arquivo só)
- `fotos/`: fotos de banco de imagens (Pexels, licença livre para uso comercial)
- `img/`: fotos reais da padaria, tiradas do Instagram @padariaboasnovasjf
- `render.yaml`: publicação no Render como site estático

Para atualizar o site no ar: altere os arquivos, faça commit e `git push`. O Render republica sozinho.
